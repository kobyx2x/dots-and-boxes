📱 Як опублікувати на GitHub та грати на iPhone/iPad Натисніть

1. GitHub: Створіть новий репозиторій на GitHub, завантажте цей файл під назвою index.html.

2. GitHub Pages: Зайдіть у Settings → Pages, у розділі Branch виберіть main і натисніть Save. Через хвилину з'явиться посилання на гру.

3. iPhone / iPad: Відкрийте посилання в Safari → натисніть кнопку «Поділитися» (квадрат зі стрілкою вгору) → «На екран «Додому»». Гра відкриватиметься на весь екран як додаток!
